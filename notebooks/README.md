# 🐍 Python A/B Testing Analysis

## 📌 Overview
This folder contains the Python analysis for the **E-Commerce A/B Testing & Conversion Rate Optimization** project.

The objective is to evaluate whether a new landing page improves conversion rates compared with the existing landing page.

## 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- SciPy
- Statsmodels
- Matplotlib

## 📊 Analysis Workflow
1. Data loading and inspection
2. Data cleaning and validation
3. Duplicate user ID analysis
4. Exploratory Data Analysis (EDA)
5. Conversion rate calculation
6. Absolute conversion difference and relative lift
7. Hypothesis formulation
8. Two-Proportion Z-Test
9. 95% Confidence Interval
10. Conversion rate visualization
11. Country-level conversion analysis
12. Daily conversion trend analysis
13. Statistical interpretation and business recommendation

## 🔍 Key Findings
| Metric | Result |
|---|---:|
| Total Users | 290,584 |
| Total Conversions | 34,753 |
| Control Conversion Rate | 12.04% |
| Treatment Conversion Rate | 11.88% |
| Conversion Difference | -0.16 percentage points |
| Z-Test P-Value | 0.905 |

## 💡 Conclusion
The analysis did not find statistically significant evidence that the new landing page improves conversions.
