
# 📊 Power BI A/B Testing Dashboard

## 📌 Overview
This folder contains the Power BI dashboard for the **E-Commerce A/B Testing & Conversion Rate Optimization** project.

The dashboard compares the performance of the control and treatment landing pages and presents the experiment findings.

## 📈 Dashboard Components

### KPI Cards
- Total Users
- Total Conversions
- Control Conversion Rate
- Treatment Conversion Rate
- Conversion Difference (Percentage Points)

### Visualizations
- Conversion Rate by Experiment Group
- Conversion Rate by Country
- Daily Conversion Rate by Experiment Group

### Interactive Slicers
- Experiment Group
- Country
- Experiment Date

## 📊 Key Results
| Metric | Result |
|---|---:|
| Control Conversion Rate | 12.04% |
| Treatment Conversion Rate | 11.88% |
| Conversion Difference | -0.16 percentage points |
| Z-Test P-Value | 0.905 |
| Significance Level | 0.05 |

## 💡 Business Recommendation
The experiment did not provide sufficient statistical evidence that the new landing page improves conversions.

**Recommendation:** Retain the existing landing page for now and investigate further before implementing the new design.
