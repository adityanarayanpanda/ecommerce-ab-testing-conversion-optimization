## 🎯 Project Highlights
- Compared control and treatment conversion rates
- Performed statistical hypothesis testing
- Calculated a 95% confidence interval
- Analyzed conversion rates by country
- Examined daily conversion trends
- Created an interactive Power BI dashboard

## 💡 Main Conclusion
The treatment landing page achieved a lower observed conversion rate than the control page. The statistical test did not establish a significant improvement.
